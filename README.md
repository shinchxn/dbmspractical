# dbmspractical

Lightweight static server and SQL scripts collection for DBMS practicals (Programs 1 to 15).

## Getting Started

### Run the Server

- **Python FastAPI:**
  ```bash
  python app.py
  ```

- **Node.js (Zero Dependency):**
  ```bash
  node server.js
  ```

### Download Scripts via Terminal

- **Fetch a single script (e.g., 10.sql):**
  ```bash
  # Linux/Mac
  curl -O http://localhost:8000/10.sql

  # Windows PowerShell
  curl.exe -O http://localhost:8000/10.sql
  ```

- **Download 1.sql and 15.sql:**
  ```bash
  # Linux/Mac
  curl -O http://localhost:8000/1.sql -O http://localhost:8000/15.sql

  # Windows PowerShell
  curl.exe -O http://localhost:8000/1.sql -O http://localhost:8000/15.sql
  ```
